# Components Reference — A–J

Back to the [feature index](./README-FEATURES.md). The complete catalog of the app
components in `src/components/` (150 app components + 32 shadcn/ui primitives; the K–Z
half is [COMPONENTS-REFERENCE-K-Z.md](./COMPONENTS-REFERENCE-K-Z.md)). Line counts are
`wc -l`. "Talks to" lists API routes and the notable lib modules.
