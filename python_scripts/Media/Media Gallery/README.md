# Media gallery

Every image format the viewer's `<img>` renderer supports.

| File                | Format | Note                                            |
|---------------------|--------|-------------------------------------------------|
| `LineChart.png`     | PNG    | matplotlib line chart (transparent-safe raster) |
| `ScatterPlot.png`   | PNG    | matplotlib scatter chart                        |
| `SamplePhoto.jpeg`  | JPEG   | photograph-style gradient                       |
| `AnimatedBall.gif`  | GIF    | animated, 24 frames                             |
| `SoftGradient.webp` | WebP   | modern compressed raster                        |
| `VectorLogo.svg`    | SVG    | hand-written vector markup                      |
| `RasterBitmap.bmp`  | BMP    | uncompressed bitmap                             |
| `AppIcon.ico`       | ICO    | multi-size Windows icon                         |
| `TinyAvatar.avif`   | AVIF   | AV1-encoded still image                         |

Videos and audio live in `../Playback/`.
