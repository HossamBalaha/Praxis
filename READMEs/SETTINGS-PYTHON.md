# Settings — Tab 3: Python (20 rows)

Back to the [settings index](./SETTINGS-REFERENCE.md). The Python tab covers the
interpreter, run behavior, type checking, profiling, docstrings, and testing. 19 bound
rows plus one action row (virtualenv creation).

## Python runtime

| Key                                  | Label                                    | Control                                 | Default            | Range/Options                                               | What it does                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|--------------------------------------|------------------------------------------|-----------------------------------------|--------------------|-------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `pythonInterpreter`                  | Python interpreter                       | Select (w-48, font-mono) + Clear button | `""` (Auto-detect) | `__auto__` + discovered envs                                | **Discovery** (`GET /api/envs`, `src/lib/python-interpreter.ts`): `$VIRTUAL_ENV`, `~/.venv`, `~/.virtualenvs/*`, conda (`conda env list --json`), pyenv (`~/.pyenv/versions/*`), uv (`uv python list`), and system python3/python. ## Type checking

**Total: 20 rows** (19 bound keys + the Create Venv action). pytest itself is driven
per-run through the Tests panel (`POST /api/test`, `POST /api/test/collect`,
