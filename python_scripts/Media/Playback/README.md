# Playback

The `<video>` and `<audio>` renderers — video files open the Video
tools, audio files the dedicated **Audio tools** (waveform player +
Audio studio) since.

| File               | Format              | Length |
|--------------------|---------------------|--------|
| `DemoClip.mp4`     | MP4 (H.264 + AAC)   | ~8 s   |
| `Screencast.webm`  | WebM (VP9 + Vorbis) | ~6 s   |
| `GradientFlow.mp4` | MP4 (H.264)         | ~30 s  |
| `LongFilm.mp4`     | MP4 (H.264)         | ~75 s  |
| `Chime.wav`        | WAV (PCM)           | ~2 s   |
| `LongTone.wav`     | WAV (PCM)           | ~45 s  |
| `DeepSession.wav`  | WAV (PCM)           | ~70 s  |
| `Melody.mp3`       | MP3                 | ~6 s   |
| `SynthMelody.mp3`  | MP3                 | ~45 s  |
| `ExtendedMix.mp3`  | MP3                 | ~70 s  |
| `VoiceNote.ogg`    | OGG (Vorbis)        | ~4 s   |
| `AmbientNoise.ogg` | OGG (Vorbis)        | ~60 s  |
| `LongAmbient.ogg`  | OGG (Vorbis)        | ~90 s  |

The long entries (30 s → 90 s) exercise the ±10 s skips, the A–B
loop window and the level meter over sustained playback.

All clips are synthesized (test sources and sines) — safe for work.
