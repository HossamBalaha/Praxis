## Auxiliary

- **`src/lib/examples-data/`** — 91 files: 89 content modules + `_helpers.ts` (the
  `mkExample` constructor) + `_tokens.ts` (the `⟦fn:…⟧` naming-style tokens). The corpus
  is ~3,690 examples: Python 2,150 (1,000 core + 800 in the 4 generated categories +
  350 in 14 × 25), every other language ~50; validated by `scripts/check-examples.ts`
  which compiles and executes every body.
- **`src/data/templates-manifest.json`** — 61 entries across 8 file kinds (python 28,
  markdown 15, gitignore 8, text 5, json 2, yaml 1, toml 1, csv 1), generated from
  `code-templates.ts`.
- **`src/hooks/`** — 7 hooks: `use-examples` (the lazy chunk loader),
  `use-keyboard-shortcuts`, `use-live-lint-diagnostics`, `use-pwa-install`,
  `use-pyright-lsp`, `use-tab-lifecycle`, `use-toast`.
- **`public/`** — the PWA manifest + icon set, `sw.js` (the app-shell precache + the
  `/api/code`//api/file` offline runtime cache), 7 spell dictionaries in `dict/`,
  `robots.txt`, `sitemap.xml`.
