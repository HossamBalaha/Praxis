# Settings — Tab 2: Formatting (13 global rows + 3 Python rows + 37 language blocks)

Back to the [settings index](./SETTINGS-REFERENCE.md). The Formatting tab has a global
section, a live **language runtimes panel** (installed-and-detected), a Python block, and
37 per-language blocks. The offline formatter engines live in `src/lib/code-format.ts`
(curly-brace family + shell, lossless: never join/split lines, never add/remove semicolons
or braces), `src/lib/formattable-kinds.ts` (the same 37 kinds — the single source of truth
gating the viewer's Formatting menus), and `src/lib/formatter-binaries.ts` (prefers real
binaries over built-ins, argv-array spawns only — never shell strings — with 60 s probe
caches, 4 s probe timeouts, a 30 s hard format timeout).

## Language runtimes panel

"Language runtimes — installed & detected" renders `runtimeStatuses` rows
(`{id, label, command, version, ok, installHint, languages[]}`): a green dot + version
when the runtime is found, a gray dot + "not found" + an amber install hint otherwise, a
per-language intro line, and a **Check again** button that re-detects (bypassing the
cache). The detection/execution mapping lives in `src/lib/language-runtimes.ts` — node (and tsx/deno/
`node --experimental-strip-types`), `matlab -batch`/octave, Rscript, bash,
java, ruby, php, `go run`, lua, perl, rustc-compile, julia, kotlin, and friends. A
"Detecting runtimes…" placeholder shows while the first detection is in flight.

## The 37 language blocks

Each block is `<section id="fmt-lang-<kind>">`: a runtime dot + version (green when a
runtime covering the block's language is ok; GraphQL shows the tooltip "A QUERY language —
it highlights, edits and formats offline, but there is no interpreter to run"; doc kinds
show "Formats offline — no runtime needed"), a title, an intro line, an "Auto-format:
`<conventions>`" line, and a bordered strip with **two selects for every block**:

- **Indent width** → `formatLangIndent[<kind>]`: `Default` (unset — falls back to the
  global `formatIndentWidth`) / 2 / 4 / 8.
- **Format on save** → `formatLangAutoSave[<kind>]`: `Default` (follows `formatAutoSaveAll`)
  / On / Off.

The `formatLangIndent` / `formatLangAutoSave` maps in the schema cover exactly these 37
kinds (the union in the `Settings` interface). Preferred real formatter binaries (`src/lib/formatter-binaries.ts`):
`prettier` (javascript, typescript, json, css — parser
scss/less by extension — html, markdown, yaml), `gofmt` (go), `rubocop` (ruby), and `ruff`
for Python (preferred over black, black fallback). Source travels over stdin.
