## toolbox/ (15 files)

- **`tool-factory.tsx`** — the shared three-pane tool scaffolding (input/options/output +
  Copy/Download) every text tool rides.
- **`tool-extra.tsx`** (6,660) — 14 `EXTRA_*_TOOLS` arrays lifting every TEXT category to
  the 30-tool minimum.
- **`tool-extra-media.tsx`** — additional media-studio tools (WebAudio graphs, pdf-lib
  stamps) lifting Audio/PDF/Image→Text to 30.
- **`toolbox-icons.tsx`** — the ONE shared per-category icon map.
- **Tabs**: `tool-data.tsx` (CSV/TSV/JSON table transforms + JSONPath) · `tool-math.tsx`
  (30 math tools over a Pratt-style evaluator) · `tool-format.tsx` (the first 12 ride the
  real offline formatter engines) · `tool-security.tsx` (WebCrypto digests/HMAC/AES-GCM/
  PBKDF2 + classic ciphers) · `tool-validate.tsx` (per-line syntax + checksum
  validators) · `tool-textanalysis.tsx` (readability/frequency/similarity) · **`image-studio.tsx`** (27 canvas ops,
  full-resolution exports) · **`audio-studio.tsx`**
  (9 tools, OfflineAudioContext + a unit-tested WAV encoder) · **`video-studio.tsx`**
  (20 tools, MediaRecorder re-encode pipeline) · **`pdf-studio.tsx`** (30+ pdf-lib ops) · **`image-to-text.tsx`** (OCR,
  ASCII art, palette, EXIF).

## settings/ · ui/
